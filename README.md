## Repository purpose

This repository contains the public-facing static site for Starless Terminal.

Current deployment:

```text
GitHub Pages
└── starlessterminal.com
```

The site is intentionally kept simple:
- static HTML/CSS
- no backend
- no database
- no CMS
- no API keys
- no tracking
- minimal external dependencies
